# Unit-tests for StellarBurgers
## **Юнит-тесты**
_веб-приложение: Stellar Burgers_

### В проекте:

#### 1. Реализованы тесты на методы (кроме класса Burger):

*   Bun (геттеры цены и названия булочки)
*    Ingredient (геттеры цены, названия и типа ингредиента )
*  Database (методы получения доступных булочек и ингредиентов)

#### 2. Использованы технологии:

* Java 11
* Maven 4.0.0
* JUnit 4.13.2
* Jacoco 0.8.7

### Как запустить тесты
`mvn clean test`
### Как сформировать отчет покрытия тестов
`mvn verify`
